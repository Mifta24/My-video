# Rencana Long Suhuf #03 Pulau Run (16:9, 1920x1080)

Sumber narasi: Suhuf-Pengetahuan-03-Pulau-Run-long-script.md (salinan identik long-v1.md Don, cek `cmp`).
Narasi TIDAK diubah. 33 adegan, 513 kata. Durasi mengikuti klip suara (target +-4:10). Tidak ada isian tambahan (BAHAN KURANG).

## Aturan tetap
- Kanvas 1920x1080, margin aman 90 px semua sisi (isi di x 90..1830, y 90..990).
- Zona: baris label y 96-166 (label SKEMA / PERUMPAMAAN di pojok kiri atas, watermark SUHUF PENGETAHUAN pojok kanan atas, tinta gelap),
  kata besar y ~185-310 (1-4 kata), gambar utama y ~320-830, caption kotak putih tepi bawah y = 990 (maks 2 baris, tidak memudar sebelum klip selesai).
- Gambar berganti tiap 3-5 detik (shot `Sh`); kamera mengambang halus di semua adegan (tidak ada diam > 4 dtk).
- 3D hanya di timbangan/tanda tanya: L-01, L-29, L-31. Sisanya 2D (kit Shorts: pulau, kapal, keranjang, kalender, lembar perjanjian, tangan menggenggam, anak mainan).
- Angka di layar hanya 1616, 1667, 3 x 1 km. Tanpa meriam/api/korban. Bendera Inggris (oranye) dan Belanda (biru) selalu seimbang.
- Dilarang: Banda 1621, angka korban/penduduk, "Run lebih berharga daripada Manhattan", harga pala, lama Courthope, kata "menyerang".
- Fakta pegangan: Manhattan dipegang Inggris (sejak 1664), Run dipegang Belanda (Breda 1667). Teks "tetap" untuk Manhattan hanya bersama label INGGRIS.

## Daftar adegan dan kebutuhan visual (shot = gambar 3-5 dtk)
BAB 1 HOOK
- L-01 Pertanyaan (~10 dtk): [3D] timbangan Manhattan vs Run, label SKEMA, "DITUKAR?" -> timbangan berubah tanda tanya 3D.
- L-02 Salam (~8 dtk): A kertas terbuka + logo "Satu lembar, satu cerita." | B detektif mainan melambai + "DETEKTIF SEJARAH".
BAB 2 SIAPA PULAU RUN
- L-03 Pulau mungil (~10 dtk): SKEMA. A peta laut, kaca pembesar detektif ke titik kecil | B titik membesar jadi pulau RUN + garis ukur "3 x 1 km" | C "KECIL SEKALI", titik di peta besar.
- L-04 Letaknya (~6 dtk): SKEMA. A peta kartun pulau-pulau (tanpa batas wilayah), "MALUKU" | B gugusan "KEPULAUAN BANDA", pulau ujung barat menyala "RUN".
- L-05 Pala dan fuli (~9 dtk): A pohon pala di pulau Run, "PALA & FULI" | B pala + fuli jatuh ke keranjang (ting).
- L-06 Rekap (~5 dtk): papan investigasi, detektif menempel gambar Run + pala, stempel "RUN = PALA".
BAB 3 KENAPA DIREBUT
- L-07 Inggris datang (~10 dtk): A kalender "1616" | B kapal Inggris berlabuh di Run, kapten mainan (topi, tanpa wajah rinci) turun.
- L-08 Surat (~7 dtk): A surat bergambar (garis acak) + tanda tangan | B mahkota mungil di sudut, "SURAT PENGAKUAN".
- L-09 Belanda ingin sendiri (~11 dtk): A kapal Belanda datang (ukuran sama kapal Inggris) | B kapal Belanda MEMELUK keranjang pala besar (lengan bawah melingkari sisi keranjang, tangan di sisi/belakang) | C "MONOPOLI" + "hanya satu yang boleh jual".
- L-10 Perumpamaan toko (~9 dtk): label PERUMPAMAAN - bukan data. A kompleks rumah + satu toko es krim | B papan "HANYA KAMI", anak-anak antre.
- L-11 Rebutan (~6 dtk): dua kapal kiri-kanan, Run di tengah, pala bersinar, saling menatap, "REBUTAN".
- L-12 Rekap (~6 dtk): papan investigasi, dua kapal + keranjang pala, benang merah ke tanda tanya.
BAB 4 DI PULAU LAIN
- L-13 Manhattan (~7 dtk): SKEMA. A peta berpindah ke pulau "MANHATTAN" | B papan "NEW AMSTERDAM" + bendera Belanda.
- L-14 New York (~4 dtk): SKEMA. papan berputar -> "NEW YORK" + bendera Inggris.
- L-15 Dua pulau (~9 dtk): SKEMA. A dua pulau berdampingan (Manhattan bendera Inggris, Run pala tanpa bendera) | B tanda tanya kecil di antaranya.
- L-16 Rekap (~6 dtk): papan investigasi dua pulau + benang merah; chip INGGRIS di Manhattan.
BAB 5 PERTANYAAN DAN PERJANJIAN 1667
- L-17 Pertanyaan (~7 dtk + jeda 2 dtk): split kiri Manhattan, kanan Run, tanda tanya besar (2D), "Tertulis kata tukar?", hitung mundur 2-1 saat jeda.
- L-18 Perjanjian damai (~10 dtk): A kalender "1667" | B lembar perjanjian turun ke meja + stempel, "BREDA 1667".
- L-19 Aturan pasal (~8 dtk): A lembar + pita "BAHASA LATIN" (tanpa teks hukum) | B dua tangan (oranye, biru) menggenggam pulau masing-masing (pulau >= 55% lebar area gambar per tangan), "YANG DIPEGANG, TETAP DIPEGANG".
- L-20 Perumpamaan kue (~9 dtk): label PERUMPAMAAN - bukan data. A dua anak di meja, piring berisi kue | B gelembung "tukar" -> tanda silang.
- L-21 Nama tidak ada (~7 dtk): kaca pembesar menyisir lembar; label RUN dan MANHATTAN di luar lembar dicoret, "TIDAK DISEBUT".
- L-22 Rekap (~6 dtk): papan investigasi, stempel "YANG DIPEGANG, TETAP DIPEGANG" di atas lembar perjanjian.
BAB 6 DI BALIK MEJA PERUNDINGAN
- L-23 Penengah (~11 dtk): A penengah mainan (topi bulu) di meja, "USUL PENENGAH" | B ia menggeser Run ke sisi Belanda dan Manhattan ke sisi Inggris (SKEMA di pulau) | C dua sisi berlabel.
- L-24 Ditolak (~6 dtk): raja mainan (mahkota) menggeleng, lembar usul kembali ke tengah, "BELUM SETUJU".
- L-25 Tekanan di sungai (~9 dtk): SKEMA. A peta sungai menuju kota ("SUNGAI") kapal Belanda masuk tenang | B kapal Inggris berlabuh, kapten menggaruk kepala, "INGGRIS MENGALAH". Tanpa meriam/api.
- L-26 Kesepakatan (~7 dtk): dua tangan berjabat di atas meja, pulau Run menempel ke sisi Belanda (klik), "RUN TETAP".
- L-27 Rekap (~6 dtk): papan investigasi, benang merah Run + Manhattan ke meja perundingan, "DIBAHAS BERSAMAAN".
BAB 7 HASIL AKHIR
- L-28 Dua hasil (~8 dtk): SKEMA. A Manhattan + bendera Inggris + chip INGGRIS + panah TETAP | B Run + bendera Belanda + chip BELANDA + panah TETAP.
- L-29 Jadi ditukar? (~11 dtk): [3D] timbangan "DITUKAR" bergoyang -> tanda tanya; "TIDAK SEPENUHNYA SALAH" + kecil "bukan tukar tertulis".
- L-30 Dua kalimat (~7 dtk): split: kiri "YANG TERTULIS" (dua tangan menggenggam pulau), kanan "YANG TERJADI" (peta dua pulau berbendera + chip), detektif mengangguk.
- L-31 Rekap (~6 dtk): [3D] timbangan nyaris rata, detektif tersenyum, "TIDAK SEPENUHNYA SALAH".
BAB 8 PELAJARAN DAN PENUTUP
- L-32 Pelajaran (~6 dtk): kaca pembesar besar di atas lembar perjanjian, "CEK" lalu "YANG TERTULIS".
- L-33 Penutup (~7 dtk): logo + "@suhufpengetahuan", kapal Inggris dan Belanda melambai kiri-kanan, kertas menutup pelan.

## Pelajaran Shorts yang diterapkan sejak awal
1. Pelukan (L-09): lengan bawah melengkung melingkari sisi keranjang, tangan terlihat di sisi/belakang keranjang. Genggam (L-19, L-30): kit GraspedIsland, pulau besar, jari di depan tepi.
2. Teks kontras tinggi: caption kotak putih + tinta; layar kapal krem diberi outline tebal.
3. Margin aman 90 px; caption maks 2 baris; potongan terakhir bertahan sampai klip selesai.
4. Kamera mengambang + objek bergoyang di semua adegan.
5. Transisi silang (Sh) tanpa frame kosong; objek tidak terpotong tepi.
6. Manhattan "tetap" hanya bersama label INGGRIS.
